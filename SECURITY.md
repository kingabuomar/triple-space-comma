# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 1.x | Yes |
| Earlier builds | No |

## Reporting a vulnerability

Please use GitHub's **Security → Report a vulnerability** flow for sensitive reports. Do not open a public issue with exploit details or private data.

For ordinary bugs that do not create a security or privacy risk, use the repository's bug-report issue template.

Reports should include the affected macOS version, app version, reproduction steps, and expected impact. Please avoid including real typed content in screenshots or logs.
